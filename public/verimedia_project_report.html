VeriMedia

Client-Side Deepfake & Media Forensics Engine Using MobileNetV2, ONNX Runtime Web, and WebGL Shaders
Authors: Yogesh Tiwari & Dhwaj Chauhan
Department of Computer Science & Engineering
Machine Learning / Computer Vision / Edge ML Project Submission

Abstract

Generative artificial intelligence models (Midjourney, Stable Diffusion XL, Flux) produce synthetic imagery visually indistinguishable from authentic photography. Social media platforms routinely strip C2PA/EXIF metadata and recompress media upon upload, creating a critical verification void. This paper presents VeriMedia, a zero-cost ($0.00 backend dependency), client-side digital forensics engine capable of detecting synthetic AI imagery, composite splices, and stripped metadata directly inside the user's web browser.

VeriMedia utilizes a fine-tuned MobileNetV2 Convolutional Neural Network (CNN) quantized to INT8 precision and executed via ONNX Runtime Web (onnxruntime-web) over WebGL and WebAssembly (WASM) execution providers. Neural classifier outputs are fused with WebGL 2.0 fragment shaders performing Error Level Analysis (ELA) and a 3×3 Laplacian high-pass spatial noise matrix to produce interpretable, multi-signal forensic reports.

2.1 Neural Classifier Training & Quantization

  1. Base Model: MobileNetV2 pre-trained on ImageNet with lower feature layers frozen (features[:10]).
  2. Data Augmentation: PyTorch pipeline introducing random JPEG compression (quality 50–95), resizing, and blur to simulate social media re-compression.
  3. INT8 Quantization & Export: Exported via torch.onnx.export to a 3.5 MB quantized ONNX binary (verimedia_mobilenet_v2.onnx).

2.2 Client-Side Inference Runtime

Executes locally inside JavaScript using onnxruntime-web:

  • Input Tensor: 1 × 3 × 224 × 224 normalized float array (ImageNet standard: μ=[0.485, 0.456, 0.406], σ=[0.229, 0.224, 0.225]).
  • Execution Providers: WebGL hardware acceleration with automatic fallback to multithreaded WASM.

5. Conclusion

VeriMedia proves that privacy-preserving, high-accuracy media forensics can be achieved at zero operational cost. By deploying an INT8 quantized MobileNetV2 classifier via ONNX Runtime Web alongside WebGL ELA shaders and Laplacian spatial noise matrix analysis, the platform provides transparent, interpretable, multi-signal verification directly inside the user's web browser.
